# موقع الأستاذ أحمد مهيرة — العلوم الطبيعية

- **الموقع:** <https://malekdjr.github.io/mehira-science/>
- **لوحة التحكم:** <https://malekdjr.github.io/mehira-science/admin/>

موقع تعريفي وتعليمي: دروس بالفيديو، اختبارات تفاعلية من كتاب الأستاذ، جدول الأفواج،
المراكز، عدّ تنازلي للبكالوريا، مساعد آلي، واستمارة تسجيل عبر واتساب.

مبني بـ HTML و CSS و JavaScript فقط، ومستضاف مجاناً على **GitHub Pages** (بدون خادم).

---

## 1. لوحة التحكم — الدخول أول مرة

اللوحة تحفظ التعديلات مباشرة في مستودع GitHub، فيُعاد نشر الموقع تلقائياً.
للدخول تحتاج **رمز دخول (Token)** يُنشأ مرة واحدة:

1. افتح <https://github.com/settings/personal-access-tokens/new> (بحساب `malekdjr`).
2. **Token name:** `Mehira admin` — **Expiration:** سنة (أو No expiration).
3. **Repository access:** اختر **Only select repositories** ثم `mehira-science`.
4. **Permissions → Repository permissions → Contents:** اختر **Read and write**.
5. اضغط **Generate token** وانسخ الرمز (يبدأ بـ `github_pat_`).
6. افتح لوحة التحكم، الصق الرمز، واضغط **دخول**.

> الرمز يبقى محفوظاً في المتصفح (إن اخترت «تذكّرني»). لا تشاركه مع أحد.
> إن ضاع أو انتهت صلاحيته: احذفه من نفس صفحة GitHub وأنشئ رمزاً جديداً.

## 2. استعمال اللوحة

| القسم | ماذا تفعل فيه |
|---|---|
| الفيديوهات | الصق رابط يوتيوب أمام كل وحدة (يُنصح بفيديو «غير مُدرج / Unlisted») |
| الدروس والاختبارات | المجالات، الوحدات، النقاط، الأسئلة، الإجابة الصحيحة، الصور |
| الأفواج | اليوم، التوقيت، المركز، الحالة (متاح / مغلق / جديد / يُعلن لاحقاً) |
| المراكز | الأسماء وروابط الخريطة |
| معلومات عامة | الهاتف، واتساب، تاريخ الباك، الأرقام، التسجيلات، الشهادات، الأسئلة الشائعة |
| المساعد الآلي | رسالة الترحيب وأجوبة أسئلة الدروس |
| الإعدادات | تنزيل نسخة احتياطية / استيراد نسخة |

- كل تعديل يبقى **مسودة** حتى تضغط **حفظ ونشر** (أو `Ctrl+S`).
- **معاينة** تعرض الموقع بالتعديلات قبل نشرها.
- بعد الحفظ يظهر التحديث على الموقع خلال **1 إلى 2 دقيقة** (قد يحتاج الزائر `Ctrl+F5`).
- الصور المرفوعة تُصغَّر تلقائياً وتُحفظ في `assets/img/uploads/`.

## 3. بنية الملفات

```
├── index.html              ← الصفحة
├── admin/                  ← لوحة التحكم (config.js = اسم المستودع)
└── assets/
    ├── css/style.css       ← التصميم والألوان
    ├── js/content.js       ← كل المحتوى (تعدّله اللوحة)
    ├── js/app.js           ← منطق الموقع
    └── img/                ← الصور (quiz/ = وثائق كتاب الأستاذ)
```

## 4. ما الذي يحفظه الموقع؟

تقدّم التلميذ في الاختبارات يُحفظ في متصفحه هو فقط (localStorage).
لا توجد قاعدة بيانات: الأستاذ لا يرى نتائج التلاميذ في هذه النسخة.

## 5. تغيير الألوان

في أعلى `assets/css/style.css`:

```css
--sky:#5CE1E6;     /* السماوي الساطع */
--green:#15B86B;   /* أخضر أزرار الاتصال */
--gold:#F7D154;    /* الذهبي */
```
